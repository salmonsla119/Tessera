# 게임 기획서 (GDD)

턴제 멀티 덱빌딩 그리드 전술 게임 — 체스판 위에서 벌어지는 발더스 게이트식 DND 전투.

이 문서는 **게임 규칙만** 다룬다. 아키텍처·일정·검증은 [PLAN.md](PLAN.md) 참조.

## 0. 한 줄 요약

제한된 코스트로 6기물 덱을 짜고, 8×8 격자에서 **팀 공용 행동력**을 배분해가며 상대 기물을 전멸시키는 비동기 턴제 PvP.

---

## 1. 기물 스탯

모든 기물은 **5개 스탯 + 스킬 1개**를 가진다.

| 스탯 | 약칭 | 역할 |
|---|---|---|
| 체력 | HP | 0이 되면 보드에서 제거 |
| 공격력 | ATK | 스킬 데미지 범위에 **가산** |
| 정신력 | SP | 스킬 사용 자원 |
| 회피 | EVA | 피격 시 d100 회피 판정 확률(%) |
| 속도 | SPD | **덱 전체 합산으로 팀 행동력만 결정** |

### 속도(SPD)의 특수성

속도는 다른 4개 스탯과 성격이 완전히 다르다.

- 이동 칸수에 **영향을 주지 않는다**. 이동 범위는 전적으로 기물 베이스의 패턴이 결정한다.
- 개별 기물에게는 **아무 효과도 없다**. 오직 덱 전체 합산값만 의미를 가진다.
- 즉 속도는 **덱빌딩 시점에 "우리 팀이 한 턴에 몇 번 움직이는가"를 구매하는 전략 스탯**이다.

이동력과 템포를 분리했기 때문에 "느리지만 튼튼한 원거리", "빠르지만 약한 근접" 같은 조합이 성립한다.

## 2. 행동력(AP)

### 2.1 기본 개념

AP는 **기물이 아니라 플레이어가 보유하는 팀 공용 자원**이다. 이번 턴에 "우리 팀 기물들을 통틀어 총 몇 번 행동시킬 수 있는가"를 나타낸다.

### 2.2 산출식

```
매치 시작 시:  teamSpeed = Σ(덱에 편성된 전 기물의 SPD)
턴 시작 시:    apPool += teamSpeed × 0.1
이번 턴 행동 횟수 = floor(apPool)
apPool -= floor(apPool)          // 소수부만 다음 턴으로 이월
```

> **`teamSpeed`는 매치 시작 시 확정되며, 기물이 죽어도 절대 줄어들지 않는다.**
> 열세인 쪽이 행동 횟수까지 잃어 더 빨리 지는 사망 스노우볼을 원천 차단하기 위한 규칙이다.

### 2.3 소수점 이월 예시

속도 합 27인 팀의 진행:

| 턴 | 이월분 | +2.7 | 이번 턴 사용 가능 | 다음 턴 이월 |
|---|---|---|---|---|
| 1 | 0.0 | 2.7 | **2회** | 0.7 |
| 2 | 0.7 | 3.4 | **3회** | 0.4 |
| 3 | 0.4 | 3.1 | **3회** | 0.1 |
| 4 | 0.1 | 2.8 | **2회** | 0.8 |
| 5 | 0.8 | 3.5 | **3회** | 0.5 |

### 2.4 행동 비용

| 행동 | 비용 | 설명 |
|---|---|---|
| 이동 | 1 AP | 해당 기물의 패턴 범위 내 1회 이동 |
| 공격 | 1 AP | 스킬 또는 기본 공격 1회 |
| 집중 | 1 AP | 해당 기물 SP +3 |

**기물당 횟수 제한은 없다.** AP가 남아 있는 한 같은 기물을 한 턴에 여러 번 이동시키거나 여러 번 공격시켜도 되고, 6기물에 골고루 나눠 써도 된다. **AP를 어디에 배분할지가 인게임 의사결정의 중심이다.**

### 2.5 UI 표기

```
행동  3 / 3     (다음 턴 +0.4)
```

소수 이월분은 항상 노출한다. 플레이어가 다음 턴 행동 횟수를 미리 계산할 수 있어야 한다.

## 3. 전투 판정

### 3.1 데미지 파이프라인

```
1. 스킬 기본 데미지 범위        [minD, maxD]              예: 2~7
2. + 공격자 ATK                 [minD+ATK, maxD+ATK]      예: ATK 5 → 7~12
3. × 거리 감쇠 배율             round(양 끝값 × 배율)      예: 거리3 ×0.70 → 5~8
   ────── 여기까지가 플레이어에게 표시되는 "예상 데미지" ──────
4. 주사위 굴림                  [min, max] 균등분포 1회 → 확정 데미지
5. 방어자 회피 판정             d100 ≤ EVA → 데미지 0 (완전 회피)
6. HP 차감
```

플레이어는 공격을 확정하기 **전에** 3단계 결과(예: `5~8`)를 보고, 확정 후 주사위 굴림 연출과 함께 결과를 받는다.

### 3.2 거리 감쇠 배율

거리는 **체비셰프 거리**(8방향 격자에서 `max(|dx|, |dy|)`)로 계산한다.

| 거리 | 1 | 2 | 3 | 4 | 5+ |
|---|---|---|---|---|---|
| 배율 | 1.00 | 0.85 | 0.70 | 0.55 | 0.40 |

공격자에게 가까울수록 강한 데미지를 입는다. 원거리 스킬은 사거리가 길지만 먼 거리에서는 위력이 크게 떨어지므로, 파고들 것인가 거리를 유지할 것인가의 판단이 생긴다.

### 3.3 회피

- **d100 ≤ EVA → 완전 회피** (데미지 0)
- **회피 상한 60%.** 상한이 없으면 회피 스택 덱이 사실상 무적이 된다.
- 회피는 데미지 확정 **후에** 판정한다. 즉 큰 데미지도 통째로 무효화될 수 있다.

### 3.4 주사위의 권위

**모든 주사위는 서버가 굴린다.** 클라이언트는 3단계까지의 예상 범위만 계산해 표시하고, 4~6단계 결과는 서버 응답으로만 받는다.

## 4. 정신력(SP)

- 공격 시 스킬의 SP 코스트를 지불한다.
- **잔여 SP < 코스트면 스킬이 잠기고 기본 공격만 가능하다.**
- **기본 공격**은 모든 기물이 무료로 보유한다: 데미지 `1~3`, 사거리 1, SP 0, 코스트 0.
- 회복
  - 자기 턴 시작 시 각 기물 **SP +1** (최대치까지)
  - `집중` 행동(1 AP)으로 해당 기물 **SP +3**

강력한 스킬일수록 SP 코스트가 높아, 연속 사용하려면 집중에 AP를 써야 한다. AP와 SP가 서로를 제약하는 구조다.

## 7. 덱빌딩 (아웃게임)

### 7.1 규칙

- **기물 1개 = 베이스 1개 + 스킬 1개**
- 기물 코스트 = 베이스 코스트 + 스킬 코스트
- 편성 **최대 6기물**
- **총 예산 30코스트**

### 7.2 전략 축

덱 전체 속도 합이 그대로 팀 AP가 되므로, 1차 트레이드오프는 이것이다:

> **느린 고화력 5기물** (개체 성능은 높지만 턴당 행동이 적음)
> vs
> **빠른 저스펙 6기물** (개체는 약하지만 턴당 행동이 많음)

여기에 근접/원거리 비율, 회피 특화 여부, SP 코스트 분포가 겹친다.

### 7.3 코스트 산정 기준선

```
베이스 코스트 ≈ round(HP/12 + ATK/3 + SP/8 + EVA/15 + SPD/6 + 이동가치)
```

이 식은 초기 기준선일 뿐이며, 헤드리스 자동 대전 결과로 재튜닝한다.

## 8. 매치 진행

### 8.1 순서

1. **매칭** — 덱을 지정해 매칭 대기열에 등록하면, 대기 중인 다른 플레이어와 짝지어져 매치가 생성된다. 비동기이므로 등록 후 접속을 끊어도 되고, 상대도 접속해 있을 필요가 없다. (구현은 [PLAN.md §5](PLAN.md) 참조)
2. **덱 스냅샷** — **대기열 등록 시점의 덱이 그대로 복사되어 매치에 들어간다.** 대기 중에 덱을 수정해도 이미 등록한 대기열에는 영향이 없고, 매치 진행 중의 밸런스 패치에도 영향을 받지 않는다.
3. **선공 결정** — 서버가 양측 d20을 굴려 높은 쪽이 선공. 동점 시 재굴림.
4. **덱 비공개 · 동시 배치**
   - 매치 시작 시 **상대 덱은 보이지 않는다.**
   - 양측이 상대를 보지 못한 채 자진 2열(16칸)에 6기물을 배치한다.
   - **양측 제출이 끝나면 덱 구성과 배치가 동시에 공개된다.**
   - 비동기 게임에서 순차 배치는 나중에 배치하는 쪽에 일방적 정보 우위를 준다. 동시 제출이어야 공평하다.
5. **공개 이후는 완전정보** — 양측 기물의 스탯·스킬·HP·SP가 모두 노출된다. 은닉은 배치 단계에서 한 번만 일어난다.
6. **턴 교대** — AP를 모두 쓰거나 턴 종료를 선언할 때까지.
7. **종료** — 상대 기물 전멸.

### 8.2 보드

- **8×8 격자**
- 플레이어 A: rank 1~2 / 플레이어 B: rank 7~8 이 각자의 배치 구역
- 장애물·지형 없음 (초기 버전)

### 8.3 승리 조건

**상대 기물 전멸.** 이것이 유일한 승리 조건이다.

### 8.4 밸런스 장치

| 장치 | 내용 | 목적 |
|---|---|---|
| 후공 보정 | 후공 플레이어는 시작 `apPool`에 **+0.5**를 얹고 시작 | 선공 어드밴티지 상쇄 |
| 서든데스 | **40턴 경과 후** 매 턴 시작 시 양측 전 기물 **HP −2** | 무한 매치 방지 |
| 턴 제한시간 | **24시간** 초과 시 자동 기권 | 비동기 매치 방치 방지 |

서든데스는 승리 조건을 바꾸지 않는다. 전멸승은 그대로 두고, 회피 특화 덱끼리 붙어 매치가 끝나지 않는 상황만 강제로 종결시킨다.
